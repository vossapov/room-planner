# Конструктор кімнати

**Сайт: https://vossapov.github.io/room-planner/**

Перетягування меблів і дверей, повороти, точні розміри, undo/redo та бібліотека концептів на GitHub. Поточна геометрія кімнати: 272 × 312 см.

## Збереження між пристроями

У правій панелі «Концепти на GitHub» можна читати спільні концепти без входу. Щоб зберігати:
1. У «Доступ для збереження» відкрий посилання створення fine-grained token.
2. Owner: **vossapov**. Repository access: **Only select repositories → room-planner**.
3. Repository permissions: **Contents → Read and write**; інші права не потрібні. Встанови обмежений строк дії.
4. Встав ключ у поле конструктора і натисни «Підключити».
5. Дай плану назву й натисни «Зберегти на GitHub».

Кожне збереження створює новий JSON у `concepts/`, після чого програма читає його з GitHub і перевіряє вміст. Попередні версії не перезаписуються. Кнопка «Оновити список» отримує актуальний список; «Відкрити» завантажує вибраний план.

**Ключ існує лише в пам’яті вкладки**, не зберігається в localStorage, JSON або репозиторії. Після перезавантаження вкладки його потрібно ввести знову. Не використовуй ключі від інших сервісів чи широкий classic token. Відкликати ключ можна в GitHub Settings → Developer settings → Personal access tokens.

Локальне автозбереження і «Мої варіанти» залишаються окремими від GitHub. «Експорт JSON» дає переносний файл для резервної копії.

## Дві проекції

Під планом завжди видно ізометричний вигляд тієї ж кімнати. Кнопки ◀ ▶ повертають його на 90°, тож усі чотири кути доступні; обраний кут запам'ятовується в браузері. Ізометрія оновлюється одразу під час редагування. У стінах прорізані реальні отвори: дверний проріз у перегородці (рухається разом із дверима) і мале вікно на вуличній стіні з підвіконням та перемичкою. Зашита ніша колишнього вікна показана заглибленням у балконній стіні. Балконний прохід належить сусідній кімнаті й тут не малюється. Ближні дві стіни не малюються, щоб кімната залишалась відкритою; ТВ показується лише тоді, коли його стіна в кадрі.

**Висоти припущені** і не є замірами: ліжко 42, стіл 74, тумба 55, конвектор 60 см; ТВ 68 см заввишки з низом на 110 см; дверний проріз 210 см, стеля умовно 250 см. Підвіконня малого вікна прийнято 90 см. Скажи фактичні розміри - підставлю.

## Керування
- Перетягування мишкою/дотиком; R - поворот, стрілки - 1 см, Shift + стрілки - 10 см.
- Ctrl+Z / Ctrl+Shift+Z - скасувати/повторити.
- Вікно та конвектор зафіксовані; у дверей можна змінити відступ, петлі й напрям відкривання.

## Розробка
```sh
python3 build_editor.py
node core.test.js
node --test cloud.test.mjs
```
`index.html` самодостатній і також працює як локальний файл. Джерела: editor.html/editor.js/core.js/cloud.mjs/cloud-ui.js; вихідні планування: presets/. GitHub Pages публікує main:/, без стороннього backend.

## Межі перевірки
Попередження показують геометричні перетини, зону крісла та буфер конвектора. Вони не гарантують безперервного проходу, теплової чи монтажної безпеки. Усі опубліковані плани та концепти публічні.
